# 번역 요청 이후 지연 개선

## 적용

- 번역·내 발언 영어 변환: Gemini 3.5 Flash-Lite, `thinking_level: minimal`.
- 답변 가이드: Gemini 3.8 Flash 유지. 단순 번역에 고급 추론 모델을 일괄 사용하지 않는다.
- 허용된 모델로 생성 요청을 바로 시작하고 사전 모델 메타데이터 조회 왕복을 제거했다. 모델이 404인 경우에만 3.6 Flash → 3.8 Flash로 대체하고 5분간 선택을 재사용한다. 인증·결제·한도 오류를 다른 모델로 반복 호출하지 않는다.
- 재시도에서 기존 번역이 사라지지 않게 유지하면서 새 출력이 따라잡으면 즉시 스트리밍을 재개한다. 기존에는 재시도 완료까지 모든 중간 출력을 감췄다.
- 문단 확정→요청 시작→첫 상태 반영→완료 지표를 분리했다. API 지표에도 모델 사전 조회를 숨기는 구간이 없다.
- 날짜 포함 범위에 대한 명시적 지침을 보강했다. `by tomorrow`는 내일까지, `before tomorrow`는 내일 전까지로 구분한다.
- 문단 나누기 / 다 말하고 번역하기의 경계와 누적 기록은 유지한다. 3초 무음 옵션의 의도적 대기나 원문 확정 대기를 없애는 변경은 아니다.

## 검증 결과

- 자동 테스트 200개 통과, 프로덕션 빌드 성공. API 입력/출처/모델 제한, 키 비노출, `store:false`, SSE 미완료 오류, 실제 준비 상태, 404 대체, 재시도 스트리밍 포함.
- 합성 9건으로 모델 3종의 같은 프롬프트를 비교했다. 최종 프롬프트 기준 첫 텍스트 중앙값: 3.8 Flash 1,970ms, 3.6 Flash는 원문 보고서 참조, 3.5 Flash-Lite 1,044ms. 3.5는 538~1,342ms였다. 모델 직접 호출 결과이며 공개 웹 체감 전체 지연과 같지 않다.
- 9건에서 부정, 금액·수량·단위, 오늘/내일·시간 전후, 조건부 승인, 계약금/보증금, 불확실성, 정중한 한국어 의도, 기한 포함 범위를 수동 검토했다. 의미 손실은 발견하지 못했지만 전문 통역 품질을 입증하는 벤치마크는 아니다. 정규식은 보조 단서이며 문장 의미를 대체하지 않는다.
- 실제 브라우저 + Google 음성 API + 새 번역 API의 합성 영어 녹음: 원문 `Could you send me the meeting agenda by tomorrow?`, 번역 `회의 안건을 내일까지 보내주시겠어요?`. 요청→첫 번역 상태 반영 773ms, 요청→완료 859ms. 캡처 시작→첫 DOM 반영은 5,539ms로, 음성 인식과 발화 종료 대기를 포함한다.
- 긴 합성 회의 문단 1건: 기존 공개 API 첫 텍스트 1,944ms/완료 4,218ms, 개선 로컬 API 첫 텍스트 595ms/완료 1,339ms. 서로 다른 실행 경로의 단건 비교이므로 개선율을 서비스 보장 수치로 사용하지 않는다.

보고서: `reports/translation-speed-2026-11-19/`. `models.json`은 초기 프롬프트 8건, `models-final.json`은 날짜 보강 후 9건이다. `browser-audio-final.txt`가 최종 음성 브라우저 증거이다. 공개 API 배포 전후의 동일 8건 비교는 후속 `http-before.json` / `http-after.json`에서 공통 id로 계산한다. 배포 전 보고서는 8건, 배포 후에는 기한 사례가 추가되어 9건이므로 전체 중앙값을 직접 혼합하지 않는다.

## 범위

단일 네트워크·시점의 합성 음원/텍스트 측정이다. 네트워크·서버 부하·문장 길이에 따라 달라진다. 상시 1초 이하나 발화 시작→번역 1초를 보장하지 않는다. 실제 현장 마이크, 소음 환경, 물리 모바일 기기에서의 성능을 이번 결과로 주장하지 않는다. 모델은 Google 내에서만 교체하며 다른 공급자로 회의 데이터를 보내지 않는다.

공식 근거: [Flash-Lite 모델](https://aistudio.google.com/docs/models/gemini-3.5-flash-lite), [모델별 thinking level](https://aistudio.google.com/docs/thinking#thinking-levels), [stateless Interactions](https://aistudio.google.com/docs/interactions-overview#data-storage-retention).
