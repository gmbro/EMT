# Maestra 실시간 받아쓰기 레퍼런스 및 EMT 개선안

작성일: 2026-10-31 KST. 범위: 공개 UI·공식 도움말 조사 및 현재 소스 비교. 제품 코드 변경·배포 없음.

## 결론

제품을 ‘실시간 받아쓰기 + 한국어 이해 + 내 영어 발언 지원’으로 설명한다. 영어 원문 아래 한국어가 누적되는 기존 요구와 세 영역 드래그 구조를 유지한다. 과거 기록은 고정하고 현재 발언의 마지막 부분만 갱신해 읽는 위치가 흔들리지 않게 한다.

## 레퍼런스에서 확인한 내용

- 공개 한국어 진입 화면: 전사/번역/더빙 모드, 언어 선택, 중심 마이크 버튼. 전사 탭 선택 시 번역 대상 언어 선택이 사라져 현재 작업이 분명해진다. 마이크 세션을 시작하거나 회의 음성을 전송하지는 않았다.
- 공식 전사 도움말: 브라우저에서 원문 자막을 표시하며, Free와 Pro 엔진·지원 기능을 구분한다. Pro의 높은 정확도는 공급자 설명이며 독립 측정 결과가 아니다.
- 공식 변경 기록: 실행 중 마이크 변경, 원문·번역 영역 크기 조절, 세션 유형별 크레딧 사용 이력 안내.
- 사전: 음성 인식을 위한 용어 목록과 인식 이후 단어 치환을 구분하고 파일 가져오기를 지원한다.
- 실제 회의 중 화면 전체, 유료 엔진, 장시간 연속 인식, 한국어·영어 품질과 지연은 이번 조사에서 테스트하지 않았다. 브라우저에서 동작한다는 설명은 기기 내 추론·외부 전송 없음의 증거가 아니다.

## 현재 구현과 차이

| 항목 | 현재 확인 | 개선 방향 |
|---|---|---|
| 시작 | 새 회의 후 별도 시작. 연결 준비 중 버튼 비활성 | 새 회의 → 음성 입력 허용 → 바로 받아쓰기. 권한 거부·오디오 공유 취소에는 입력 선택 복구 |
| 받아쓰기 | 원문/번역 쌍을 발화별 표시 | 마지막 발화만 인식 중임을 표시. 확정 원문과 이전 번역 위치 유지. 발화가 길면 의미 단위로 누적 |
| 표시 지연 | 원문 즉시 업데이트, 번역은 350ms 실행 대기 및 24자 변경량 등 조건 | 원문 표시와 번역 요청 주기를 독립 관리. 번역은 시간·의미 경계·큐 길이에 따라 조정 |
| 스크롤 | 120개 발화 페이지와 이전/다음 버튼. 자동 따라가기 있음 | 가변 높이 가상 스크롤로 연속 탐색. 위로 읽을 때 위치 보존, 새 발화 개수 표시 |
| 상태 | 처리 띠, 발화별 상태, 일부 전역 오류 문구 | 소리 입력 없음 / 원문 인식 지연 / 번역 대기 / 연결 복구 중 / 저장 실패를 구분. 원문과 번역 채널 상태 독립 표시 |
| 용어 | 단일 용어 입력값을 음성 vocabulary 및 번역 glossary에 사용 | 회의별 인식 용어와 번역 대응표를 분리. 회사별 세트·가져오기. 원문을 덮어쓰는 자동 치환은 기본 제외 |
| 비용 | 실행 중 텍스트 토큰·음성 초·재연결 계측. 새로고침 시 초기화 | 회의별 처리량·실패/재시도·지연을 로컬에 저장. 실제 요금과 추정치를 구분 |
| 가이드 | 질문/키워드·간격에 따라 생성, 미확인 약속 차단 및 기본 질문 대체 | 각 제안에 근거 발화 시각과 ‘조건 확인/우려 제기/다음 단계’ 의도 표시. 사용자가 읽는 카드는 유지 |

## 권장 화면

- 상단: 회의명 / 입력 장치 / 상태 / 시작·일시정지 / 종료. 글자 크기와 영역 조절 유지, 상세 진단·용어는 설정에 둔다.
- 왼쪽: ‘실시간 받아쓰기’. 영어 원문 바로 아래 한국어. 한국어 발언은 원문만. 확정 구간은 고정, 수정 가능한 현재 구간은 낮은 강조색과 인식 중 표시.
- 오른쪽: ‘내 발언’. 한국어 입력 및 마이크, 생성된 영어 복사. 영어 결과를 읽는 동안 스크롤 위치를 고정한다.
- 하단: 답변 가이드 1개 우선. 근거 발화와 한국어 의도 + 영어 표현. 대안은 클릭 생성. 새 가이드는 도착 표시 후 교체.
- ‘받아쓰기만’ 옵션은 추가 비용 없이 번역/가이드를 잠시 끄는 용도. 기본은 영어→한국어 번역 켬. Maestra의 더빙·공유 기능은 현재 회의 도우미의 우선 구현 범위에 넣지 않는다.
- 모바일: 기록/내 발언 탭과 접근 가능한 가이드. 키보드가 열려도 입력창·변환 버튼 유지. PC에서만 가능한 탭 오디오 기능은 환경에 맞게 표시.

## 성능 개선 우선순위

1. **입력 진단 및 표시 계측**: 사용 장치명·입력 레벨·오디오 전송·첫 원문·첫 번역 도착을 각각 측정한다. 소리가 안 들어오는 상황과 서버가 늦은 상황을 구분한다. 다른 참석자의 PC 음성을 들으려면 마이크 또는 지원되는 회의 탭 오디오 중 맞는 입력을 고르게 한다.
2. **연속 표시**: 모든 원문 업데이트를 우선 표시하며 화면 반영은 animation frame마다 모은다. 장식용 타이핑 애니메이션으로 표시를 늦추지 않는다. 확정 원문은 되돌리지 않고 마지막 가설만 수정한다.
3. **번역 요청 제어**: 캐시된 확정 문장을 재사용한다. 자잘한 수정은 병합하고 의미 단위가 충분하면 전달한다. 부정·금액·날짜·조건 수정 시 관련 문장을 다시 검토한다. API 호출 한 번으로 들어오는 번역 스트림은 바로 표시한다.
4. **오디오 안정성**: 기존 무음 게이트는 단순 RMS 기준이므로 잡음·매우 작은 목소리·원거리 음성에서 검증한다. 낮은 음량을 무조건 버리거나 무응답을 전부 장애로 간주하지 않는다. 필요 시 검증된 음성 구간 감지기와 비교하고 처음부터 무거운 모델 다운로드를 요구하지 않는다.
5. **모델 비교**: 현재 모델과 후보를 같은 음원·용어·문맥으로 측정한다. 처음부터 엔진을 교체하지 않는다. 비용·누락·지연을 함께 보고, 변경 전보다 나빠지는 경우 원복한다.
6. **장시간 렌더링**: 읽는 위치와 발화 ID를 유지하는 가상 스크롤, 음성 인식과 저장 작업 분리. 회의록 검색 및 파일 내보내기 접근성을 개선한다.

## 검증 계획과 목표 (아직 달성 결과 아님)

| 검증 | 방법 / 목표 |
|---|---|
| 첫 원문 | 측정 기준은 첫 음성 입력 프레임. 깨끗한 테스트 음원에서 첫 원문 1초 이하를 목표로 측정하고 중앙값·95백분위·목표 초과율 함께 보고 |
| 첫 번역 | 원문 전달 가능한 의미 단위가 생긴 시점부터 측정. 첫 번역 2초 이하 목표. 발화 시작부터의 지연도 함께 측정하며 의미 단위 기준만으로 목표 달성을 판정하지 않음 |
| 인식 품질 | 같은 영어 음원 WER, 한국어 CER, 금액·날짜·고유명사·부정·조건 누락을 수동 검수. 숫자 서식 정규화와 실제 누락을 구분 |
| 지속성 | 120분 실제 시간 연속 재생, 20~60초 침묵, 네트워크 단절·복귀, 장치 변경, 1만 자 이상. 확정 원문 중복/소실 및 조용한 중단 여부 확인 |
| 화면 | Chrome/Edge 실제 실행, 모바일 Chrome/Safari 실제 기기에서 스크롤·키보드·재개 검증. 단순 viewport 검증은 실제 기기 검증으로 보고하지 않음 |
| 비용 | 같은 10분·60분 음원에 대해 음성 전송 초, 요청·재시도 수, 확인된 입력/출력 토큰 측정. 확인되지 않은 사용량과 Google 실제 청구를 별도 표기 |
| Maestra 비교 | 가능하면 동일한 비민감 음원·같은 입력 환경으로 A/B. 실제 접근 가능한 엔진과 요금제를 명시하고 마케팅 문구를 측정치로 사용하지 않음 |

진행 순서: 입력·지연 진단 → 받아쓰기 연속 표시 및 번역 요청 제어 → 연속 스크롤 → 회의별 용어·사용량 → 가이드 근거 표시 → 모델 A/B.
