# 받아쓰기 지연 개선 및 배포 검증 — 2026-11-02

## 적용 범위

- 로컬 Qwen: 첫 미리보기 1.5초 → 0.8초, 다음 1.6초, 이후 1.5초 간격.
  모델 준비 단계에서 합성 무음으로 초기 추론을 준비한다.
- 로컬 Qwen: 누적 음성 재인식 시 첫 단어부터 다시 출력되는 부분으로
  화면 원문이 짧아지거나 유효한 번역 요청이 취소되지 않게 수정했다.
  실제 단어 수정과 최종 결과는 그대로 반영한다.
- 공통: 원문 의미가 수정되면 이전 임시 번역을 취소하고 최신 요청을 처리한다.
  원문 뒤에 단어가 추가되는 경우에는 기존 번역을 계속 표시한다.
- 공통: 번역 슬롯이 사용 중일 때 0ms 반복 타이머가 CPU를 점유하지 않게 했다.
- 공개 Google 음성: PCM 전송 단위 100ms → 50ms. 무음 전후 보존 시간과
  연결 복구 버퍼의 전체 음성 길이는 유지한다. 모델은 변경하지 않았다.

## 실제 측정

동일한 합성 영어 WAV를 IAB 브라우저에서 실시간 속도로 재생했다.
측정 시작은 캡처 시작이며, 파일 앞의 무음도 포함한다. 실제 회의 마이크가 아니다.

| 항목 | 변경 전 1회 | 최종 코드 독립 세션 2회 |
| --- | --- | --- |
| 첫 원문 표시 | 3,253ms | 2,454 / 2,468ms |
| 첫 번역 DOM 표시 | 4,877ms | 3,895 / 3,640ms |

최종 영어 원문은 두 번 모두 `Could you send me the meeting agenda by tomorrow?`.
한국어 예제도 `회의 일정을 내일 오후 세 시로 변경해 주세요.`로 완료됐다.
원문 1초 / 번역 2초 목표는 미달이다. 평균적인 성능, 실사용 정확도,
120분 지속성, 모바일 성능을 입증하는 결과가 아니다.
첫 번역은 진행 중인 원문의 임시 번역이며 최종 번역 완료 시간이 아니다.

`after-browser-1.json`은 중간 구현의 회귀 측정으로 최종 결과에 포함하지 않는다.
`after-browser-warm-cache.json`은 같은 세션 반복이므로 독립 비교에서 제외했다.

## 검증 및 배포

- 자동 테스트 151개 통과, 빌드 성공, production npm 의존성 감사 0건.
- 빌드 결과에 로컬 API 키 값이 포함되지 않는지 검사했다 (미검출).
- Qwen의 외부 Origin 403 / 잘못된 음성 400을 실제 확인했다.
- 공개 사이트 영어·한국어 음성 API, 부정문 번역, 내 발언 영어 변환,
  추천 답변 생성 성공. 해당 예제의 부정 표현이 유지됨을 확인했다.
- 환경 파일, 테스트, 보고서, Qwen 로컬 엔드포인트/worker가 공개 주소에서 404.
- 외부 Origin으로 공개 번역·음성 인증 API 접근 시 403.
- 공개 빌드: `d9b4676bfc0a`, https://emt-theta.vercel.app/.
  빌드 메타데이터의 앱 소스 해시 일치 확인 (Vercel 설정 파일만 플랫폼 차이).

공개 사이트는 Google 음성이다. Qwen은 http://127.0.0.1:4174/ 에서 이 Mac의
MLX로 실행한다. Vercel에 Qwen 추론 서버를 배포한 것이 아니다.
API 사용료 악용을 완전히 막는 사용자 인증/영속적 할당량 시스템은 없다.
현재 출처 검사·입력 제한·프로세스별 요청 제한은 전체 보안 감사가 아니다.
