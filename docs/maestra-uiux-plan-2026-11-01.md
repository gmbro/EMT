# 석변의 미팅 뿌시기 — Maestra 화면 기반 UI/UX 개편안

작성일: 2026-11-01. 상태: 구현 전 기획. 이번 문서는 앱 변경·배포를 의미하지 않는다.

## 근거와 범위
- 사용자가 제공한 9개 Maestra 스크린샷의 화면 배치와 조작 흐름을 기준으로 한다. 서비스 내부 구현이나 실제 성능을 추정하지 않는다.
- 23.25.24 / 23.25.45: 중앙 모드·언어 선택, 원형 시작 버튼.
- 23.24.15: 전폭 받아쓰기, 문단 왼쪽 파란 선, 하단 중앙 녹음 제어.
- 23.26.12 / 23.27.05: 좌우 원문·번역, 누적 문단, 인식 중 회색 표시.
- 23.24.52 / 23.25.02 / 23.27.21: 종료 후 상태·다운로드·TXT/DOCX 선택.
- 23.27.35: 기록 상세, 상대 시각, 내보내기, 녹음 재생.
- 로고와 제품명은 석변의 미팅 뿌시기를 유지한다. 레이아웃·색조·버튼 위치·전환을 가깝게 재현한다.
- 이번 최신 요청을 기준으로 번역 화면의 기본 배치를 좌우 원문/번역으로 변경한다. 이전의 원문 아래 번역 방식은 보기 옵션으로 유지한다.
- 추천 답변·내 발언은 기존 기능을 유지한다. 더빙·다국어·화자 분리·AI 요약은 기본 개발 범위에 포함하지 않는다.

## 화면과 사용자 흐름
설정 → 시작 → 연결 중 → 실시간 → 일시정지/재개 → 종료 처리 → 완료 → 기록 상세/내보내기.
연결 복구 중, 마이크 권한 거절, 저장 실패, 일부 번역 실패는 별도 상태로 표시한다.

### A. 시작 화면
- 흰색 전폭 화면, 중앙 약 576px 설정 영역, 은은한 외곽 경계.
- 제목: 오늘 어떤 회의를 시작할까요?
- 모드: 번역 / 실시간 받아쓰기. 기본 번역. 내보내기는 시작 모드가 아니라 종료/기록 화면의 액션이다.
- 언어: 영어·한국어 자동 감지 또는 영어/한국어 지정. 1차 대상 언어는 영어·한국어만 노출.
- 번역 기본값: 영어 원문 → 한국어. 회의 중 한국어는 원문 유지, 내 발언은 별도 영어 변환.
- 입력: 마이크 / 탭 오디오. 지원하지 않는 환경에는 탭 오디오 선택을 비활성화하고 이유를 선택 부근에 표시.
- 추천 답변 기본 켜짐. 전문 용어·회의 목적·글자 크기는 설정에 수납.
- 중앙 아래 빨간 원형 마이크 버튼 80px. 한 번 누르면 권한 요청과 연결을 진행한 후 자동으로 시작하며 두 번째 시작 클릭을 요구하지 않는다.
- 시작 전에 Google 음성·텍스트 전송 안내를 짧게 한 번 노출하고, 상세 내용은 설정에서 확인 가능.
- 날짜별 기존 회의는 별도 기록 버튼으로 접근. 새 디자인에서 이전 IndexedDB 데이터를 그대로 읽는다.

### B. 실시간 번역 화면
- 상단 장식·카드 제목을 줄이고 텍스트 영역을 화면 대부분에 배치.
- 좌측 50% 영어 원문, 우측 50% 한국어 번역. 가운데 얇은 구분선과 드래그 핸들.
- 각 발화에 영구 ID를 주고 원문과 번역을 같은 행으로 정렬. 양쪽이 하나의 스크롤을 공유해 길이가 달라도 대응 문장이 어긋나지 않게 한다.
- 각 문단 왼쪽 파란 세로선, 확정 문장은 진한 남색, 임시 인식은 회색과 작은 인식 중 표시. 색만으로 상태를 전달하지 않는다.
- 기록이 적을 때는 하단부터 시작하고, 높이가 차면 최신 내용이 하단에 남도록 위로 누적된다.
- 기존 확정 문장은 다른 발화로 덮어쓰지 않는다. 재인식·번역 교정은 해당 발화 ID의 내용만 갱신한다.
- 위로 스크롤하면 자동 추적 중단, 하단에 새 발화 N개 / 실시간으로 버튼 표시.
- 각 열 상단 복사 버튼, 오른쪽 아래 전체 화면 버튼. 보기 전환으로 원문 아래 번역 배치도 제공.
- 하단 고정 컨트롤: 좌측 제품명·회의 기록, 중앙 일시정지/빨간 종료/입력 장치, 우측 설정/보기/언어.
- 종료는 마지막 원문·번역의 처리가 끝날 때까지 상태를 보여준다. 실패한 일부 문장도 보존하고 재시도할 수 있어야 한다.

### C. 실시간 받아쓰기 + 추천 답변
- 받아쓰기 모드는 전폭 원문을 표시한다. 번역 요청은 보내지 않아 비용을 줄인다.
- 두 모드 모두 추천 답변 패널 사용 가능. 기본 높이 약 180px, 접기·확대·높이 드래그 지원.
- 추천 답변은 한국어 의도 위, 실제 말할 영어 아래. 기본 1개, 대안 보기로 최대 3개.
- 기준 발화 시각과 관련 질문을 짧게 표시. 원문 수정 시 오래된 제안임을 알리고 새로 생성 가능.
- 발언 중 매 조각마다 생성하지 않는다. 질문·안건 전환 등 의미 있는 확정 발화를 기준으로 생성, 같은 문맥의 중복 요청 억제.
- 발언자의 확정되지 않은 승인·일정·약속을 만들어내지 않는다. 사실이 부족하면 구체적인 확인 질문을 제안한다.
- 내 발언 만들기는 하단 패널의 별도 탭. 한국어 텍스트/음성 → 정중하고 간결한 영어, 원문·결과·복사 제공.
- 내 발언 초안은 실제 회의에서 말한 내용으로 취급하지 않고 회의 원문 기록과 구분 저장.
- 같은 마이크를 내 발언에 사용할 때 입력 소유권을 전환해 이중 녹음·이중 과금을 막고, 종료 시 회의 듣기로 복귀.

### D. 종료와 내보내기
- 종료 후 기록 화면을 그대로 유지. 하단 중앙에 회의 종료됨 + 저장 상태, 기록 보기 / 내보내기 제공.
- 내보내기 팝오버: TXT / DOCX / JSON. PDF는 인쇄용 레이아웃과 브라우저 PDF 저장을 지원하는 방식으로 분리.
- 내용 선택: 원문 / 번역 / 원문+번역. 타임스탬프 포함, 추천 답변 포함, 내 발언 초안 포함은 독립 옵션.
- 추천 답변·초안은 기본 제외하며 선택 시 별도 부록으로 명확히 구분.
- TXT는 UTF-8, DOCX는 실제 OOXML 문서로 생성한다. 확장자만 바꾼 텍스트를 제공하지 않는다.
- JSON은 데이터 보존·백업용. 가져오기 기능은 파일 검증과 함께 별도 구현 단계로 분리.
- 일부 번역이 끝나지 않았으면 내보내기 전에 건수와 현재 상태를 표시하고, 내보낸 파일에도 미완료로 표시.
- 파일 생성은 브라우저에서 수행. 내보내기를 위해 회의 전체를 외부 서버로 추가 전송하지 않는다.

### E. 기록 상세
- 넓은 읽기 화면, 상단 뒤로가기·날짜·길이·발화 수·내보내기.
- 발화별 상대 시각과 원문/번역 보기, 검색, 원문 수정·해당 번역 재시도.
- 스크린샷의 화자 2는 화자 분리 결과가 있을 때만 제공 가능. 현재는 화자 번호를 추정해 표시하지 않는다.
- 녹음 재생 바는 실제 저장된 오디오가 있을 때만 노출. 현재 텍스트 저장만으로 재생 기능을 만들 수 없다.
- 오디오 저장은 2차 기능: 시작 전 사용자가 선택, IndexedDB 청크 저장, 용량 부족 안내, 보관·삭제 제어, 실제 녹음 시각과 발화 매핑. 기존 기록에는 재생 불가 상태가 정상이다.
- AI 요약은 요청 시 1회 생성하는 후속 기능. 음성 인식·번역 품질 검증 후 도입한다.

## 시각 기준
- 배경 #FFFFFF, 본문 남색 #344568, 보조 #7A808A, 포인트 #3182F6, 녹음/종료 #F24F67, 테두리 #E5E7EB.
- 자체 호스팅 Pretendard 유지. 원형 버튼과 pill 형태의 설정·언어 선택, 얕은 그림자.
- 데스크톱 실시간 본문: - 20px / 기본 24px / + 28px, 줄 간격 1.45. 장시간 회의용으로 많은 기록을 읽을 수 있게 조절.
- 1920px 화면은 제공 이미지와 배치·비율 비교, 1440px/1280px에서도 주요 제어가 가려지지 않게 검증.
- 모바일: 좌우 강제 분할 대신 발화별 원문 아래 번역. 하단 제어는 44px 이상 터치 영역, 키보드·safe-area 반영.
- 입력 포커스·버튼 이름·키보드 조작·200% 확대를 지원. 전체 화면 API 미지원 시 화면 내부 확대 사용.

## 구현 구조와 데이터
- src/main.jsx의 전체 화면 셸을 SetupScreen, LiveWorkspace, SessionControls, AssistanceDock, SessionReview, ExportDialog로 분리.
- useMeeting.js의 기존 전사·번역·재연결 엔진은 보존하고 UI 상태 전환과 분리한다.
- transcript record ID를 원문/번역 정렬 키로 사용. timestamp는 캡처 기준 상대 시각과 실제 생성 시각을 구분.
- session에 mode, sourceLanguage, targetLanguage, startedAt, endedAt, durationMs 추가. 이전 기록은 기본값으로 호환.
- 오디오 파일이 없는 기록은 hasAudio=false. API 지원 없는 화자·재생 데이터는 생성하지 않는다.
- 원문-only 모드에서는 미리보기·확정 번역 API 경로를 모두 차단하되 추천 답변 요청은 독립 토글로 유지.
- 시작/정지/재개/종료는 명시적 상태 기계로 중복 캡처·중복 요청·종료 후 갱신을 막는다.
- 반복 클릭, 새로고침, 네트워크 끊김에도 확정 기록이 사라지지 않게 저장 실패를 별도 표시.

## 성능·비용 검증 기준
- 목표: 첫 원문 1초 이하 / 첫 번역 2초 이하. 평균만 제시하지 않고 p50·p95·최댓값·오류율과 조건을 보고.
- 클릭→연결 완료, 첫 음성 샘플→첫 원문, 첫 음성 샘플→첫 번역, 발화 확정→번역 확정을 구분 계측.
- 원문/번역은 수신 즉시 표시. 타자기 효과·인위적 애니메이션 대기 금지.
- 받아쓰기 전용의 번역 호출 0건, 추천 답변 끔 상태의 가이드 호출 0건을 검사.
- 토큰 비교는 동일 음성·동일 설정에서 변경 전후 입력/출력 토큰과 요청 수를 측정. 비용 절감률은 실측 없이 약속하지 않는다.
- 긴 문맥은 최근 확정 발화와 용어집 중심으로 제한. 캐시 재사용은 원문·문맥·용어집이 일치할 때만 허용.
- UI 렌더링 부하와 모델 지연을 분리해 측정. 2,000개 이상 발화로 스크롤·정렬·저장 성능 검증.

## 단계와 완료 조건
1. 로컬 UI: 시작/실시간/완료/기록 상세를 고정 데이터로 구현, 첨부 9개 화면과 같은 해상도에서 시각 비교. 기존 데이터 유지 확인.
2. 실제 기능: 엔진 연결, 원문-only 모드, 가이드·내 발언 패널, 일시정지/재개·복구. 영어→한국어, 한국어 음성·텍스트→영어, 거절·수치·조건문 검증.
3. 내보내기: TXT/DOCX/JSON, 선택 항목과 원문 일치, 한글 인코딩·긴 문장·누락·중복 검사. DOCX 실제 문서 앱 열기 확인.
4. 운영 검증: Chrome·Edge 데스크톱, 실제 모바일과 뷰포트 검사를 구분. 120분 실제 속도 음성 입력 + 화면 + 번역 + 저장 종합 시험. 미실행 환경은 명시.
5. 배포: 테스트·빌드 통과 후 공개 버전/파일 확인, 새 회의→번역→종료→내보내기 브라우저 점검. 기존 기록 복원 회귀 검사.

## 확인된 현황과 한계
- 현재 앱은 TXT 내보내기가 있으며 DOCX/녹음 재생은 새 구현이 필요하다.
- 직전 첫 번역 시험 중앙값 3.073초, 2초 목표 미달. 보고서: reports/early-preview-latency-2026-10-31.json.
- 수정 후 120분 시험은 elapsed 7200.80초, 자동 재연결 12회, 보고된 errors 0으로 완료.
- 이 시험은 Node에서 합성 PCM을 반복 전송한 전사-only 시험이다. 실제 입력 오디오 7027.31초, 전송 7039.31초(재연결 시 중복 전송 포함). 브라우저 화면·번역·물리 마이크·내용 누락률을 검증한 결과가 아니다.
- 위 결과로 120분 전체 통역 무중단 또는 정확도를 보장하지 않는다. reports/endurance-120min-2026-11-01.json 참조.
