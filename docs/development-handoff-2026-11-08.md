# 개발 인수인계 — 2026-11-08

## 현재 실행 구성

- 공개 사이트 https://emt-theta.vercel.app/ 는 Google 음성 인식과 Gemini 텍스트 번역을 사용한다.
- 로컬 Qwen 실행판은 Qwen3-ASR 1.7B로 음성을 처리한다. 번역·추천 답변·내 발언 영어 변환을 사용하면 텍스트를 Google로 보낸다.
- 로컬 Qwen 기본값은 받아쓰기만, 추천 답변 자동 생성 꺼짐이다. 번역은 화면에서 켠다.
- Windows 설치 스크립트와 패키지는 제공하지만 Windows 실기기 추론·마이크·성능 검증은 필요하다.
- 원문/한국어 번역 좌우 2분할, 연속 문단, 분할 너비 조절, 글자 11~17px(기본 14px), 보조 영역 숨기기를 제공한다.
- 회의 기록은 브라우저 IndexedDB에 저장한다. 다른 기기로 옮길 기록은 내보내기를 사용한다.

## 다른 노트북에서 시작

1. 저장소 복제 후 `npm ci` 실행.
2. Google 음성/텍스트 기능을 사용하려면 `.env.example`을 `.env.local`로 복사하고 `GEMINI_API_KEY=` 뒤에 본인 키를 입력.
3. `npm run dev` 실행 후 터미널에 표시된 주소 열기. 기본 주소는 http://localhost:5173/.
4. Windows Qwen은 `local/windows/guide.txt`와 `docs/windows-installation-2026-11-02.md`를 먼저 확인. Git으로 복제한 폴더에서는 저장소 루트에서 `py -3.12 local/windows/setup.py`로 설치하고 `npm run dev:qwen`으로 실행한다. `.cmd` 파일은 공개 ZIP의 루트에 배치해 사용하는 바로가기다.
5. Mac의 기존 MLX 환경은 자동 복제되지 않는다. Python 가상 환경과 모델 설치 후 `npm run dev:qwen`으로 http://127.0.0.1:4174/ 실행. 설치 참고는 `local/qwen/README.md`.
6. 키·Python 가상 환경·모델 캐시·node_modules·브라우저 회의 기록은 GitHub로 전달되지 않는다.

## 구현된 비용 절감

- 원문·언어·문맥·용어집·작업이 같은 번역 결과를 메모리 캐시에서 재사용.
- Google 음성 전송 시 매우 낮은 음량의 무음 제외. 발화 시작/끝 버퍼 유지.
- 최근 및 관련 과거 발언을 길이 제한 안에서 선별하는 문맥 구성.
- 임시 번역의 작은 원문 증가에 대한 요청 억제.
- 답변 가이드의 동일 문구 중복 제외 및 최소 호출 간격(질문 12초, 기타 30초).

## 제안 단계인 다음 개발

1. 첫 번역은 빠르게 시작하고, 이후 안정된 앞부분을 재사용하면서 새 의미 구간 중심으로 번역. 부정·금액·조건·원문 수정 시 재검토 필요.
2. 용어집 전체 대신 현재 발언에 관련된 항목 선별.
3. 표현이 달라도 같은 질문이면 기존 가이드 재사용.
4. 중요한 모호한 문장에 한정한 고성능 모델 검토 여부 비교.
5. 같은 합성 음원으로 입력/출력/생각/캐시 토큰, 미집계 요청, 첫 원문/첫 번역 시간, 의미 오류를 전후 비교. 전체 절감률은 공급자 청구 내역과 대조.

실제 회의 내용을 Google에 보내는 것은 허용된 상태다. OpenAI 전환은 비교 제안 단계이며 실제 회의 내용을 OpenAI에 보내는 동의는 별도로 확인해야 한다.

## 남은 UI·입력 이슈

- 사용자가 원문과 번역을 위에서부터 쌓고, 영역이 차면 최신 내용이 보이도록 요청했다. 현재 CSS는 아래 정렬이다. 해당 수정 작업은 사용자의 중지 요청으로 수행하지 않았다.
- `Requested device not found` 오류가 보고됐다. 현재 시작 오류는 원시 메시지를 표시한다. 실제 입력 장치/권한 확인과 한국어 오류·복구 안내 개선이 필요하다.
- 회의 기록 버튼은 듣기/번역/입력 등 `locked` 상태에서 비활성화된다. 회의 중 목록만 열고 세션 전환을 제한하는 개선은 설명만 했으며 구현 전이다.
