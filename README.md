# 석변의 하비 뿌시기

한국어 ↔ 영어 현장 통역 웹 앱입니다. 노트북·데스크톱 Chrome을 주 사용 환경으로 설계했습니다. 음성, 전사, 번역, 답변은 기기에서 처리하며 서버 추론 API를 호출하지 않습니다.

## 사용법

1. **영어 → 한국어** 또는 **한국어 → 영어**를 고릅니다.
2. 자막 모드를 선택하고 **통역 준비**를 누릅니다. 첫 다운로드는 Wi-Fi에서 진행하세요.
3. **듣기 시작**을 누르고 마이크 권한을 허용합니다. 내가 다른 언어로 말할 때는 듣기를 멈춘 뒤 통역 방향을 바꾸고 다시 시작합니다.

설정에서 마이크 대신 **회의 탭 오디오**를 선택할 수 있습니다. 지원되는 PC에서 회의 탭과 ‘탭 오디오 공유’를 함께 선택하세요.

## 자막과 번역

- 원문을 먼저 표시하고 같은 문장 바로 아래에서 번역을 갱신합니다. 번역이 느리거나 실패해도 원문은 유지되며 **다시 번역**할 수 있습니다.
- 브라우저 로컬 인식은 중간 자막을 사용합니다. 다운로드한 음성 모델은 말하는 중 1.2초 간격으로 누적 음성을 확인하고 생성되는 단어를 표시합니다. 중간 자막은 인식이 진행되며 수정될 수 있습니다.
- 최종 음성은 650ms 동안 쉬거나 연속 6초에 도달했을 때 확정 처리합니다. 음성 인식과 번역은 별도 워커·대기열을 사용해 느린 번역이 새 원문 표시를 막지 않도록 했습니다.
- 중간 번역은 준비된 Chrome 로컬 번역기에서 최신 문장을 병합해 처리합니다. 최종 문장의 번역을 우선하며, 브라우저 내장 번역기가 없으면 최종 인식 결과부터 다운로드한 번역 모델로 번역합니다.
- 최근 **10,000자**의 원문과 번역을 합산해 메모리에 유지합니다. 한도를 넘으면 오래된 문장부터 정리하고 화면에 안내합니다. 문자가 잘리지 않도록 Unicode 코드 포인트 기준으로 셉니다.
- 대화를 위로 스크롤하면 자동 이동을 멈추고 **최신 자막으로** 버튼을 표시합니다. 복사·TXT 저장은 사용자가 눌렀을 때 기기 안에서 수행합니다.
- **직접 입력**으로 문장을 붙여넣어 번역할 수 있습니다. 긴 문장은 모델 입력 한도에 맞게 분리해 번역하며 원문을 조용히 잘라 보내지 않습니다.
- 한국어 답변을 영어로 만드는 입력과 선택적인 기기 내 자동 답변 제안은 화면 아래에 접어 두었습니다.

## 음성 모델과 속도

| 모드 | 실행 모델 | 용도 |
| --- | --- | --- |
| 실시간 우선 | 지원되는 로컬 SpeechRecognition, 미지원 시 Whisper Base q8 CPU | 빠른 중간 자막 |
| 정확도 우선, GPU 지원 | Whisper Large v3 Turbo q4 WebGPU | 더 큰 다국어 음성 모델 |
| 정확도 우선, GPU 미지원·실행 실패 | Whisper Small q8 CPU | 기기 호환성 확보. 실제 모델과 대체 안내 표시 |

Turbo는 q4 가중치와 fp32 활성화를 사용하며 q4f16은 사용하지 않습니다. GPU 준비·실행에 실패하면 Small로 한 번 재시도합니다. 모델 이름이 모든 발화의 정확도를 보장하지 않으며, 최초 준비·GPU 셰이더 컴파일·CPU 성능·현장 소음에 따라 지연이 달라집니다. 모든 기기에서 지연 없는 통역을 보장하지 않습니다.

번역은 Chrome의 로컬 Translator를 우선 사용합니다. 없으면 한국어→영어는 OPUS-MT, 영어→한국어는 M2M100을 기기에서 실행합니다. M2M100이 이미 준비된 경우 양방향에 재사용합니다. 브라우저 내장 번역기를 이용하려면 최신 데스크톱 Chrome과 지원 환경이 필요합니다. 모바일에는 다운로드한 모델 경로를 제공하지만 실제 휴대폰에서의 속도·메모리 지원을 보장하지 않습니다.

음성 모델과 런타임의 첫 다운로드는 실시간 우선 약 110MB, 정확도 우선 GPU 약 792MB, CPU 약 282MB입니다. 내장 모델을 사용할 수 없으면 번역 모델이 추가됩니다(한국어→영어 약 123MB, 영어→한국어 약 646MB). 모델 캐시가 유지되면 다시 사용합니다. 전체 오프라인 웹 앱을 제공하는 것은 아닙니다.

**예제 테스트**는 마이크 권한 없이 실제 AudioWorklet·음성 구간 분리·기기 내 인식·번역을 실행합니다. 합성된 한국어·영어 예제이며 중간 자막에는 ‘예제 음성 인식 중’을 표시합니다. 실제 현장의 마이크·소음·전문 용어 정확도와 구분해서 평가하세요.

## 개인정보와 보안

- 앱은 Vercel의 API 키를 읽거나 클라이언트에 포함하지 않습니다.
- 브라우저 SpeechRecognition은 `processLocally=true`를 실제 지원하는 인스턴스에서만 사용합니다. 서버 인식으로 전환하지 않습니다.
- 호환 모델과 ONNX 실행 파일은 동일 사이트의 고정 정적 경로에서 GET으로 받습니다. `connect-src 'self'`를 유지하며 음성 업로드, 전사 전송, 서버 추론, 분석 SDK를 사용하지 않습니다. 브라우저 내장 모델의 다운로드는 브라우저가 관리합니다.
- 회의 내용은 이 탭의 메모리에만 보관하며 새로고침·내용 지우기로 사라집니다. 사용자가 저장을 누르면 로컬 TXT 파일이 생성됩니다. 브라우저 캐시에는 모델만 저장합니다.
- 캡처한 영상 프레임을 읽거나 저장하지 않습니다. 듣기 중지 시 오디오 트랙과 컨텍스트를 정리합니다.
- COOP/COEP로 지원 기기에서 WASM 최대 4개 스레드를 사용합니다. 나머지는 단일 스레드로 실행합니다.
- 처리 대기가 크게 쌓이면 듣기를 멈추고 이미 받은 문장을 처리합니다. 음성을 조용히 버리지 않습니다.

## 개발과 배포

```sh
npm install
npm run prepare:models
npm run dev
npm test
npm run build
```

`prepare:models`는 고정 리비전의 공개 모델 65개 파일(약 1.87GB)과 설치된 라이브러리에 맞는 실행 환경을 준비합니다. 파일 크기와 SHA-256을 검증하고 `public/models/`, `public/runtime/`에 복사합니다. 가중치·캐시는 Git에 넣지 않습니다. Vercel은 빌드 중 모델을 준비하고 생성된 `dist/`를 정적으로 배포합니다. 다운로드·무결성 검증이 실패하면 빌드를 중단합니다.

`node scripts/prepare-models.mjs --verify-only`로 모델과 런타임을 다시 검사할 수 있습니다. 테스트는 리샘플링, 구간 분리·중간 자막, 로컬 전용 인식, 스트리밍, 시간 제한·취소, 연속 입력 병합, 10,000자 한도, 긴 문장의 무손실 분할을 검증합니다. 브라우저 실추론과 현장 마이크 검사는 별도로 수행해야 합니다.
