# 석변의 미팅 뿌시기

영어·한국어 회의 받아쓰기, 영어→한국어 번역, 한국어→영어 발언 작성, 문맥 기반 답변 가이드, 회의 기록 내보내기를 제공하는 웹앱입니다.

공개 서비스는 https://emt-theta.vercel.app/ 입니다. 다른 노트북에서 개발을 이어갈 때는 [2026-11-08 인수인계](docs/development-handoff-2026-11-08.md)를 먼저 확인하세요.

## 개발 환경 실행

```sh
git clone https://github.com/gmbro/EMT.git
cd EMT
npm ci
# .env.example을 .env.local로 복사하고 GEMINI_API_KEY 설정
npm run dev
```

기본 주소는 http://localhost:5173/ 입니다. 포트가 사용 중이면 터미널에 표시된 주소를 확인하세요. Vite가 같은 사이트의 번역·음성 토큰 API를 제공합니다. 공개 서비스와 이 기본 개발 모드는 Google 음성 API를 사용합니다.

API 키는 서버 전용 `.env.local`에 설정합니다. 키에 `VITE_` 접두사를 붙이지 마세요. 키·모델·가상 환경·브라우저 기록은 Git에 포함하지 않습니다.

## 로컬 Qwen 받아쓰기

음성을 해당 컴퓨터의 Qwen3-ASR 1.7B로 처리하려면 Python 실행 환경과 모델을 설치한 후 `npm run dev:qwen`을 실행합니다. 주소는 http://127.0.0.1:4174/ 입니다.

- Apple Silicon Mac의 MLX 설치·실행은 [Qwen 안내](local/qwen/README.md)를 참고하세요.
- Windows x64의 Python 3.12/Node.js 22+ 설치 계획과 검증 범위는 [Windows 안내](docs/windows-installation-2026-11-02.md), [상세 사용법](local/windows/guide.txt)에 있습니다. Git 복제본에서는 저장소 루트에서 `py -3.12 local/windows/setup.py`로 설치하고 `npm run dev:qwen`으로 실행합니다. Windows 실기기 성능은 아직 검증이 필요합니다.
- 로컬 기본값은 받아쓰기만, 추천 답변 자동 생성 꺼짐입니다. 이 조합은 Gemini 키 없이 시작할 수 있습니다. 번역·가이드·내 발언 영어 변환을 켜면 텍스트를 Google로 전송합니다.
- 모델과 실행 환경은 기기마다 설치합니다. 공개 사이트를 여는 것으로 Qwen이 자동 실행되지는 않습니다.

## 화면과 회의 기록

- 원문과 한국어 번역을 좌우 두 영역의 연속 문단으로 표시하고 가운데 경계를 드래그해 너비를 조절합니다. 한국어 발화는 원문을 표시합니다.
- 본문 기본 크기는 14px이며 설정에서 11~17px을 선택합니다. 날짜·상태·검색은 12px입니다.
- 하단 답변 가이드와 내 발언 만들기는 언제든지 숨길 수 있습니다. 한국어로 말하거나 입력한 발언을 영어로 작성하고, 별도로 회의 문맥에 맞는 한국어·영어 답변을 제안합니다.
- 회의 기록은 해당 주소의 브라우저 IndexedDB에 저장합니다. TXT/DOCX/JSON 내보내기를 지원합니다. 다른 기기·브라우저·주소와 자동 동기화하지 않습니다.
- 듣기·번역·발언 작성 중에는 회의 기록 열기와 새 회의가 제한됩니다. 일시정지 후 남은 처리가 끝나면 사용할 수 있습니다.
- 녹음 파일은 저장하지 않습니다. 브라우저 저장 공간·메모리·절전·네트워크 상태에 따른 제한은 있습니다.

## 비용과 데이터 흐름

공개 서비스는 음성과 텍스트를 Google에 보냅니다. 로컬 Qwen 모드는 음성을 루프백 서버에서 처리하고 텍스트 API 기능에 필요한 문맥만 Google로 보냅니다. 텍스트 번역은 Gemini 3.6 Flash를 우선 사용하고 모델 404일 때 3.8 Flash를 사용합니다.

번역 결과 캐시, Google 음성의 보수적인 무음 전송 제외, 관련 문맥 선별, 답변 가이드 중복 제외·호출 간격 제한을 구현했습니다. 추가 의미 구간 중심 번역과 관련 용어집 선별 등 다음 최적화는 인수인계 문서에 제안 단계로 명시했습니다. 실제 전체 비용 절감률은 아직 청구 내역 대조가 필요합니다.

일회성 음성 토큰은 서버에서 발급하고 장기 키는 서버에 둡니다. Origin 검사·입력 제한·프로세스별 요청 제한을 적용하지만, 공용 서비스의 영속적 사용자별 할당량 시스템은 별도 과제입니다.
