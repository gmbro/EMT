# 이전 기기 내 음성 경로 검증 — 2026-10-28

이 보고서는 음성 외부 전송 허용 전의 측정입니다. 현재 기본 경로는 Google Live Translate이며 [현재 README](../README.md)와 실시간 음성 보고서를 참고하세요.

배포·Git push·커밋을 하지 않았습니다. 개발 서버는 http://localhost:5173/ 입니다.

## 제품 화면

- 상단에는 제품명·설정·새 회의만 남겼습니다.
- 새 회의에서 화면 대부분을 쓰는 팝업을 열고 음성 인식을 자동 준비합니다. 별도 통역 준비·음성 예제·직접 입력 버튼은 제품 화면에서 제거했습니다.
- 영어→한국어와 한국어→영어 두 칸을 유지하고, 아래에 한국어 우선·영어 후속 답변 가이드를 둡니다. 가이드를 접으면 자막 영역이 더 넓어집니다.
- 기본829×954 화면에서 짧은 합성 대화12개(각 방향6개) 중10개가 온전히 표시되고, 답변 가이드3개가 함께 보이는 것을 DOM 경계로 확인했습니다. 왼쪽6개·오른쪽4개가 전체 영역 안에 들어왔습니다. 긴 발언이나 작은 화면에서 동일 개수가 항상 보인다는 보장은 아닙니다.
- 날짜별 기록, 기록 열기, 새 회의, 창 닫기 후 보존, 새로고침 후 원문·번역·답변 가이드 복원을 확인했습니다. 기록은 이 브라우저에 저장되며 서버 동기화는 없습니다.
- 390px viewport override는 실행했으나 실제 DOM 폭이829px로 유지돼 모바일 크기의 실측 검증으로 인정하지 않았습니다. 모바일 기기 성능·마이크 검증은 하지 않았습니다.

## 실제 추론

평가 데이터는 작성한 합성 문장과 고정 예제 음성입니다. 실제 회의 녹음은 사용하지 않았습니다.

- 브라우저 AudioWorklet/VAD→기기 Whisper→Gemini 경로에서 영어 음성은 “Could you send me the meeting agenda by tomorrow?”로 인식됐고 한국어 번역이 완료됐습니다.
- 한국어 음성은 “회의 일정을 내일 오후 3시로 변경해주세요.”로 인식됐고 “Please reschedule the meeting for 3 PM tomorrow.”로 번역됐습니다.
- 별도 합성 문장10개를 같은 useMeeting 큐로 실제 번역해 총12개가 완료됐습니다. 원문·번역의 두 칸 분류와 자동 가이드 갱신을 확인했습니다.
- 초기 가이드가 업무 진행 상태·기한을 임의로 제안하는 사례를 발견했습니다. 가이드를 범위·세부 내용·조건에 대한 확인 질문3개로 제한한 뒤 실제 출력3개가 약속 없는 질문임을 확인했습니다. 모든 입력에서의 무오류를 보장하지 않습니다.

## 속도와 미달 사항

텍스트 번역의16건 재측정은 첫 토큰 중앙값1,504.5ms, 완료 중앙값1,687ms입니다. 최초 설정의 첫 토큰 중앙값2,105.5ms 대비 약29% 줄었지만 **1초 이내 중앙값은 달성하지 않았습니다.** [원시 결과](translation-gemini-fast-reviewed-2026-10-28.json)를 참고하세요.

음성의 언어 판별용 추가 인코딩을 제거해 하나의 분석·디코딩 과정에서 언어를 고른 뒤 전사를 이어가도록 수정했습니다. 브라우저 고정 예제의 최종 구간이 처리 큐에 들어간 시점부터 번역 완료까지:

| 방향 | 최종 구간 처리 시간 | 그중 번역 단계 |
| --- | ---: | ---: |
| 영어→한국어 | 7,794ms | 1,336ms |
| 한국어→영어 | 7,198ms | 1,365ms |

이 시간은 음성 인식·대기·번역을 포함하지만 발화 시작부터 전체 대기시간을 잰 수치는 아닙니다. 수정 전 같은 예제의 구간 처리 시간은 약15초였습니다. 현재 기기 내 음성 경로는 사용자가 요구한 전체1초 통역에 미달합니다. 실시간 국가행사 수준·모든 브라우저·모든 기기 지원도 검증하거나 보장하지 않습니다.

Node CPU에서 같은 최종 단일 분석 모델의 예제 전사는 영어668ms·한국어647ms였습니다. Node와 브라우저 수치를 혼동하면 안 됩니다.

## 오류 수정·보안 점검

- Vite가 public runtime의 `?import`를 차단하던 문제를 고쳤습니다. 고정된 두 런타임 모듈만 개발 미들웨어에서 직접 제공합니다.
- 내장 브라우저에서 두 런타임의4스레드 초기화가 완료되지 않아, 시작을 확인한 전용 단일 WASM 스레드를 사용합니다. CPU 경로는 더 작은 CPU 런타임을 씁니다.
- Transformers4.3.1의 언어 생략은 영어 고정이므로 자동 감지로 간주하지 않습니다. 첫 언어 토큰에서 영어·한국어만 고른 뒤 transcribe 토큰을 강제합니다.
- 개발 중 Fast Refresh가 실행 엔진을 정리한 뒤 준비 상태만 남기지 않도록 생명주기 처리를 수정했습니다.
- API키는 브라우저 JS 번들에 없고 `.env.local`은 Git에서 제외됩니다. 회의 음성의 외부 전송은 추가하지 않았습니다.
- 허용된 원문·최근 문맥·용어집만 Google Gemini로 보냅니다. `store:false`를 사용하며 앱은 번역을 서버에 저장하지 않습니다. Google 별도 데이터 처리 정책은 적용됩니다.
- 입력 검증, 키 비노출, 스트림 완료, 다운로드 이어받기, 음성 구간, 양방향 언어 판별,10,000자 한도, 날짜별 기록과 가이드 복원 등 **74개 자동 검사 통과**, 최종 Vite 빌드 통과를 확인했습니다.

실제 방음·잡음·복수 발화자·마이크 권한·장시간 회의·전문 통역사 평가는 별도입니다. 이번 검증에서 마이크 권한을 대신 허용하거나 주변 음성을 녹음하지 않았습니다.
