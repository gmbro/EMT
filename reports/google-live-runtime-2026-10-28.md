# Google 실시간 통역 로컬 검증 — 2026-10-28

이 보고서는 배포 전 측정입니다. 이후 사용자의 배포 승인에 따라 [운영 배포 및 검증](deployment-2026-10-28.md)을 완료했습니다.

사용자가 회의 음성의 Google API 전송도 허용한 뒤 구현했습니다. 기존 기기 내 음성 처리 조건을 변경했습니다. **로컬만 반영했으며 배포·Git push·커밋은 하지 않았습니다.** 주소는 http://localhost:5173/ 입니다.

## 변경 결과

- 새 회의 팝업에서 시작하면 Google Live Translate에 연결합니다. 브라우저 모델·WASM·WebGPU 준비는 필요하지 않습니다. 준비 단계에서 로컬 모델 워커를 생성하거나 가중치를 받지 않는 자동 검사도 통과했습니다.
- 영어·한국어 대상 스트림을1개씩 열어 두 언어를 자동 분류합니다.100ms PCM을 직접 Google에 전송하고 원문·번역을 도착하는 대로 표시합니다.
- 실시간 번역은 임시 결과로 표시합니다. 문장이 마무리되면 최근 문맥·용어집을 반영한 Gemini 3.6 Flash 번역으로 최종 보정합니다. 원문의 “변경”이 실시간 예제에서는 단순 schedule로 나타난 사례가 있어, 최종 보정의 reschedule 의미 보존을 확인했습니다.
- 음성·회의 텍스트는 Google로 전송됩니다. 앱은 이를 서버에 저장하지 않으며 회의 원문·번역·가이드는 브라우저에 저장합니다. Google 별도 데이터 처리 정책이 적용됩니다.
- 장기 API키는 서버에 두고 모델·대상 언어가 제한된1회 토큰만 브라우저에 제공합니다. 새 연결은1분, 해당 토큰 메시지는30분으로 제한합니다.

## 브라우저 실제 추론

고정 영어·한국어 예제 음성을 AudioWorklet 경로로 전송했습니다. 주변 마이크나 실제 회의는 녹음하지 않았습니다.

| 방향 | 최종 원문 | 최종 번역 |
| --- | --- | --- |
| 영어→한국어 | Could you send me the meeting agenda by tomorrow? | 내일까지 회의 안건을 보내주실 수 있나요? |
| 한국어→영어 | 회의 일정을 내일 오후 3시로 변경해 주세요. | Please reschedule the meeting to 3 PM tomorrow. |

| 측정 | 영어→한국어 | 한국어→영어 |
| --- | ---: | ---: |
| 스트림 시작→첫 원문 | 3,124ms | 3,339ms |
| 스트림 시작→첫 번역 | 3,321ms | 3,537ms |
| 마지막 유성 프레임→첫 번역 | 505ms | 209ms |
| 마지막 유성 프레임→최종 보정 완료 | 약3,991ms | 약5,005ms |

첫 번역은 임시 표시이며 최종 보정 완료와 다릅니다. 스트림 시간에는 예제 앞의 무음도 포함됩니다. 마지막 유성 프레임은100ms PCM의 RMS0.012 기준입니다. **말하기 시작부터1초 이내 또는 최종 보정까지1초를 달성한 결과가 아닙니다.** 두 고정 예제이므로 일반적인 중앙값·정확도·기기 성능 보장으로 해석하면 안 됩니다.

[브라우저 원시 결과](google-live-browser-2026-10-28.json), [직접 WebSocket 원시 결과](live-google-probe-2026-10-28.json)에 실제 문장과 시각을 남겼습니다. 직접 WebSocket 예제의 첫 미리보기는 음성 파일 끝 이후 약650ms·16ms였습니다. 브라우저와 측정 기준이 달라 합산하지 않았습니다.

기존 텍스트 평가16건은 첫 토큰 중앙값1,504.5ms·완료 중앙값1,687ms, 정규식51/56 통과입니다. 정규식은 품질 점수가 아니며 의미 검토와 한계는 [번역 비교 보고서](translation-quality-review-2026-10-28.md)를 참고하세요.

## 화면과 저장

상단에는 제품명·설정·새 회의만 남겼습니다. 넓은 팝업의 왼쪽은 영어→한국어, 오른쪽은 한국어→영어이며 답변 가이드는 한국어 우선·영어 후속입니다. 가이드는 임의의 약속을 만들지 않는 확인 질문3개로 제한합니다.

829×954 기본 화면에서 저장된 짧은 합성 대화12개 중10개가 온전히 보이고 가이드3개가 함께 표시되는 것을 DOM 경계로 확인했습니다. 각 패널은 독립 스크롤·최신 자막 이동을 지원합니다. 긴 문장·다른 화면에서 같은 개수가 항상 보인다는 보장은 아닙니다.

날짜별 기록, 새 회의, 팝업 닫기, 새로고침 후 원문·번역·가이드 복원을 확인했습니다. 회의당 최근10,000자를 유지합니다. 화면에 남긴 데이터와 스크린샷은 검증용 합성 문장입니다.

## 연결·보안 검증

- 실제 Google 세션에서 복원 핸들을 받고, 복원 가능 상태에서 새 일회성 토큰을 발급해 다시 연결한 뒤 원문·번역을 수신했습니다. [원시 결과](live-resumption-probe-2026-10-28.json)를 남겼습니다.
- 복원 불가 상태에서는 이전 핸들로 바로 재연결하지 않고 새 복원 가능 상태를 기다립니다. 재연결 중 최대5초 프레임을 보관합니다. 반복 실패·응답 정지·버퍼 초과는 전송을 멈추고 알립니다.
- 연결 준비 중 창을 닫을 때 인증 요청 취소·마이크 트랙 종료, 원문·번역 조각 결합, 마지막 단어 보존, 반대 언어 중복 제외, PCM 무손실 프레이밍, 제한 토큰, 출처·입력 검증, 키 비노출, GoAway 복원과 버퍼링,10,000자 한도, 날짜별 기록·가이드 복원 등 **87개 자동 검사 통과** 및 빌드 통과를 확인했습니다.
- 키는 브라우저 번들에 포함하지 않습니다. 음성 모델 다운로드는 제품 기본 경로에 없습니다. 이전 로컬 모델 코드는 기준선 재현을 위해 남겨두었습니다.
- 실제 마이크 권한, 현장 소음·동시 발화·긴 행사·모바일 실기기·전문 통역사 독립 평가는 수행하지 않았습니다. 장시간 무중단·전문 통역 수준·모든 브라우저를 보장하지 않습니다. 공용 배포 전의 전역 사용자 인증·비용 제한도 별도 사항이며, 현재 배포는 보류합니다.
