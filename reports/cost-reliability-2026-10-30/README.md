# 2026-10-30 음성 연결·비용 최적화 검증

## 확인한 원인
- 기존 watchdog은 마지막 텍스트 응답으로부터 14초가 지나면 새 음성의 응답 대기 시간과 무관하게 회의를 중단했다. 장시간 침묵 후 첫 PCM을 보내는 상황을 가짜 시계로 재현했다.
- 중간 번역은 원문이 요청 시점과 완전히 같을 때만 화면에 반영됐다. 계속 길어지는 문장은 번역이 완료돼도 숨겨지는 상태였다.
- 구두점 없는 확정 원문은 turnComplete를 받아도 미완성으로 남을 수 있었다.
- 스크린샷 기기의 원시 네트워크 로그는 없으므로 모든 현장 지연 원인을 확정한 것은 아니다.

## 변경
- 새 음성부터 응답 대기 시간 측정. 12초 무응답에는 audioStreamEnd로 확정 유도, 24초 무응답에는 재연결. 네트워크 단절도 제한적으로 자동 복구. 재연결은 분당 최대 2회, 재개 핸들이 없으면 미완성 원문을 보존하고 끊긴 구간 확인 안내.
- 이어지는 원문은 번역된 앞부분부터 표시. 원문 수정/부정어 변경은 오래된 번역 표시를 차단. 확정된 문장별 캐시 재사용, 작은 글자 추가로 불필요한 요청 억제.
- 매우 낮은 음량의 무음만 전송 제외. 400ms 시작 버퍼 및 1.2초 끝 여유 유지. 실제 마이크/잡음 환경에 따라 절감률은 다름.
- 답변 가이드는 동일 문구 재생성 제외, 질문 외 신호 최소 30초 간격. 검증되지 않은 약속을 생성하면 추가 API 재시도 없이 표시된 기본 확인 질문으로 대체.
- 페이지 실행 동안 음성 입력·전송 초, 재연결 수 계측. 텍스트 사용량 미확인 요청은 계속 표시. 전송량은 청구액이 아니며 총 비용 측정은 Google 청구 내역 대조가 필요.
